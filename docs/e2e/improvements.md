# UX 개선 대장

> 결함 대장(`findings.md`)이 「틀린 것」을 담는다면 여기는 **「맞게 돌지만 더 쉬울 수 있는 것」**을 담는다. 등급 대신 **규모**(S 문구·토큰 한 줄 / M 컴포넌트 한 벌 / L 흐름·데이터 변경)와 **근거**(시나리오 행·클릭 카운트)를 적는다.
> 상태 — `open` / `planned` / `done(<커밋>)` / `wontfix(사유)`. ID — 코드 조사 선등록 `U-pre-<n>`, 실행 중 관찰 `U-<n>`.
> 관찰 기준은 `journey.md`의 체크리스트 ①~⑦.
